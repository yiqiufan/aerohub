# 构建来源核对案例

## RACER 多候选核对

一次交付核对发现：当前源相对旧短程基线有4项诊断源差异，相对最近飞行有2份配置差异；候选源清单还包含2项Python缓存。逐文件核对确认旧基线与当前候选各自的源码和产物仍匹配，因此应选择匹配版本，不能把旧飞行证据用于当前工作树。

该核对验证身份识别方法，没有验证新的清单schema、自动更新流程或跨版本飞行回退。ABI变化后的反向消费者已重编译并有当前候选运行证据；不由此规定其他项目相同包列表。精简身份与运行摘要见[交付核对](../../../deployment/airsim/demos/racer_multi_flight/delivery-review.json)。
