# RACER 多机协议案例

案例用于解释契约核查，不规定车辆规模或验收数值。以下历史阶段不是项目最新完成状态。

## RACER 多机协议

RACER 的末位 ground-map slot 是该版本实现特例，不推广为其他算法的 N+1 规则。

RACER 双机地面已观测配对响应消费及双向地图块整合，但缺全机轨迹、停止确认和正常清理，不能推导多机飞行或其他共享地图实现通过。后续飞行不能改变该地面轮本身的证据等级。成员映射、共同地图几何和实际消费的方法保留在主Skill。当前接入与版本范围见[双机交付说明](../../../deployment/airsim/demos/racer_multi_flight/DELIVERY_REVIEW.md)。
